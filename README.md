# Gestor de Tareas
## Descripcion: 
Programa de consola escrito en Python para agregar y consultar tareas. Las tareas se guardan temporalmente en una lista mientras el programa está abierto.
## Funcionalidades:
- Agregar tareas con título y descripción.
- Validar que el título no esté vacío.
- Listar las tareas con su número, título, descripción y estado.
- Asignar el estado inicial Pendiente a cada tarea.
- Mostrar un mensaje cuando todavía no hay tareas.
- Salir del programa desde el menú.
- Avisar si se ingresa una opción no válida.

## Estructura del Proyecto:
gestor-de-tareas/
├── main.py
└── README.md

main.py contiene el código del programa y README.md explica el proyecto.

## Conceptos Tecnicos:
- Funciones para organizar el código.
- Listas para almacenar las tareas durante la ejecución.
- Diccionarios para guardar los datos de cada tarea.
- Ciclos while para repetir el menú.
- Condicionales if y elif para procesar las opciones.
- Entrada de datos con input() y salida con print().
- Validación y limpieza de texto con strip().
- Recorrido numerado de tareas con enumerate().

## Dependencias:
Se requiere Python 3. El programa solo usa funciones y módulos incluidos en Python; no necesita instalar paquetes adicionales.

## Instalacion:

1.Instala Python 3 desde python.org, si aún no está instalado.
2.Guarda el código en un archivo llamado main.py.
3.Abre una terminal en la carpeta del proyecto.

## Ejecucion 

Ejecuta el programa desde la terminal:
|
```
python main.py
```

Si tu sistema usa el comando python3, ejecuta:

```
python3 main.py
```
